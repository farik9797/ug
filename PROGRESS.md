## Ключевые решения
- Чистый CSS на токенах, а не Tailwind: проще перенести в WP-тему, всё через `tokens.css`.
- Страницы собираются из партиалов (шапка, подвал, форма, контакты), чтобы правка шла в одном месте.
- GSAP, а не Motion: статика → WordPress (правило CLAUDE.md).
- Фото с Wikimedia Commons, а не генерация: ключей нет, Kling/Higgsfield платные — не запускали без согласия.
