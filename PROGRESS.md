## Ключевые решения
- Чистый CSS на токенах, а не Tailwind: проще перенести в WP-тему, всё через `tokens.css`.
- Страницы собираются из партиалов (шапка, подвал, форма, контакты), чтобы правка шла в одном месте.
- GSAP, а не Motion: статика → WordPress (правило CLAUDE.md).
- Фото: сгенерированы в Google Flow (Nano Banana 2.1, 0 кредитов, 2K) вместо Wikimedia — временно, до реальных фото клиента. Flow открывать в Chrome на Mac mini.
- Неизвестное за клиента не пишем: вопросы FAQ с ответом «[уточнить…]» в JSON сборка не выводит; цен, кейсов, брендов и сроков на сайте нет.
- Превью закрыто от поиска (`preview: true`): noindex и `Disallow: /`.
